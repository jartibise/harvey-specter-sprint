## Summary

Scaffold a basic Next.js project using `create-next-app` with default options for use in a web design sprint with AI instruction.

## Setup

- Tool: `npx create-next-app@latest`
- Scaffolded in-place inside `harvey-specter-sprint/`
- TypeScript: No
- ESLint: Yes
- Tailwind CSS: No
- `src/` directory: No
- App Router: Yes
- Custom import alias: No

## Result

A working Next.js app runnable via `npm run dev`, ready for instructor-directed development.
